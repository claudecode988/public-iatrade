# Données du forward test (TradeInsight)

Branche écrite automatiquement par GitHub Actions. Argent fictif uniquement.

- `forward/config.json` : configuration gelée.
- `forward/journal.jsonl` : une ligne par décision ou résultat, ajout seulement, chaque ligne contient l'empreinte SHA-256 de la précédente.
- `forward/resume.json` : résumé lu par le site.
- `forward/mesure-longue.json` : mesure sur environ 12 mois, chaque semaine.
